## Installation

- **Windows** : `Lumen-TeX-Setup-<version>.exe`. Si Windows affiche « Windows a protégé votre ordinateur », cliquer sur « Informations complémentaires » puis « Exécuter quand même ».
- **macOS** : `-arm64.dmg` pour les Mac Apple (M1 et suivants), `-x64.dmg` pour les Mac Intel. Les fichiers macOS et Linux arrivent une dizaine de minutes après la publication. Ouvrir le .dmg et glisser Lumen TeX dans Applications. Au premier lancement, macOS bloque l'app (pas de compte développeur Apple) : aller dans Réglages Système → Confidentialité et sécurité → « Ouvrir quand même ». Cette étape n'est demandée qu'une fois ; les mises à jour suivantes s'installent depuis l'app.
- **Linux** : `.deb` pour Ubuntu et Debian (double-clic, ou `sudo apt install ./Lumen-TeX-<version>-amd64.deb`), sinon `.AppImage` pour toutes les distributions (le rendre exécutable : clic droit → Propriétés → « Autoriser l'exécution », ou `chmod +x`). Les mises à jour suivantes s'installent depuis l'app.
